One sentence, up to 200 characters, on the best advice I ever received.

## Entry

> My father said never borrow money to look rich, and twenty years later I still hear him every time I want something I can't afford.

## Program

`main.py` (Python 3 standard library only) writes the sentence to
`$MAKEFUN_OUTPUT_DIR/entry.txt`. The output is a fixed string, so every
run is byte-identical.

Run it with:

```sh
python3 main.py
```
